# Every Cubic Graph Admits a 2-Quasi-Bisection

Aleksandr Mamleev and Daniil Shapko

Every finite simple subcubic graph of even order admits a 2-quasi-bisection. The two classes differ in size by at most two, and each monochromatic connected component has at most two vertices. The accompanying Lean 4 formalization proves the subcubic theorem and derives the cubic case as a corollary.
